YogaFlow interactive requirements prototype

Open index.html in a modern browser. No server or installation is required.

Use the "Preview as" selector to switch among Studio Manager, Studio Staff,
Instructor, and Customer views. The manager view contains all seven core
use-case areas: schedule, pass purchase, pass status, class check-in, schedule
management, record corrections, and reports. The customer and instructor
views are narrower previews; their exact permissions need stakeholder approval.

The data is illustrative and is saved only in this browser's local storage.
Use "Reset sample data" in the sidebar to return to the starting state.

Suggested demonstration path:
1. View and filter the schedule.
2. Record a sample 10-Class Pass for Alex Morgan.
3. Check Alex into Gentle Yoga using the new pass.
4. Observe the balance change and duplicate check-in prevention.
5. Review the roster and management report.
6. Reverse the check-in with a reason in Corrections.

This is a requirements mockup, not a production system. It does not charge
cards, verify senior eligibility, enforce confirmed pass expiration dates,
handle workshop attendance, or connect to Yoga H'om records. These policies
remain to be confirmed in requirement elicitation.
